# Visual novel starter

This starter treats Meat2D as a scene, input, packaging, and presentation
runtime for dialogue-first games. It includes a dialogue-state loop, choice
advance input, a stage/portrait layout, and an obvious seam for adding a font,
audio mixer, localization table, save slots, and branching story data.

Use this when the primary game loop is conversation, exploration between
scenes, and player choices rather than physics or cellular simulation.
