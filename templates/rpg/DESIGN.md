# RPG starter

This starter provides a top-down RPG foundation: a small explorable arena,
party/player state, interactable markers, and a turn/encounter seam. Add a
tilemap importer, inventory/equipment components, quests, dialogue, save
slots, and combat rules without replacing the engine's scene or input APIs.

The cellular world remains optional for destructible maps, elemental hazards,
and simulation-driven encounters.
